# CaptureIt 사용자 매뉴얼

CaptureIt는 Windows 시스템 트레이에서 동작하는 가벼운 화면 캡처 도구입니다.
별도의 메인 창 없이 트레이 아이콘으로만 조작하며, 캡처한 화면을 PNG 파일로
지정한 폴더에 저장합니다.

---

## 1. 시작하기

### 요구 사항
- Windows (Windows 전용 앱입니다)
- .NET 10 데스크톱 런타임

### 실행
- 실행 파일을 실행하면 창이 뜨지 않고 **시스템 트레이(작업 표시줄 오른쪽 알림 영역)** 에
  CaptureIt 아이콘이 나타납니다.
- 앱은 **한 번에 하나만** 실행됩니다. 이미 실행 중일 때 다시 실행하면 새 인스턴스가
  뜨지 않습니다.
- Windows 시작 시 자동 실행되지 않으므로 필요할 때 직접 실행하세요.
- 트레이 아이콘이 보이지 않으면 작업 표시줄의 **∧ (숨겨진 아이콘 표시)** 버튼을
  눌러 확인하세요.

---

## 2. 기본 사용법

트레이 아이콘을 **마우스 오른쪽 버튼**으로 클릭하면 메뉴가 나타납니다.

| 메뉴 | 설명 |
|------|------|
| **Capture Region** | 영역을 드래그해서 선택한 부분만 캡처 |
| **Capture Full Screen** | 전체 화면 캡처 (모니터 여러 대면 선택) |
| **Settings** | 저장 폴더 · 파일 이름 · 단축키 · 캡처 지연 설정 |
| **Exit** | 앱 종료 |

캡처가 **성공하면 아무 알림도 표시하지 않고 조용히** 파일만 저장됩니다.
실패했을 때(단축키 충돌, 저장 폴더 문제 등)만 Windows 알림이 표시됩니다.

---

## 3. 영역 캡처 (Capture Region)

1. 트레이 메뉴에서 **Capture Region**을 선택하거나 단축키를 누릅니다.
2. 모든 모니터 화면이 어둡게 덮이는 오버레이가 나타납니다.
3. 캡처할 영역을 **드래그**해서 선택합니다.
4. 영역을 확정하려면:
   - 마우스 버튼을 **떼거나**, 또는
   - 영역을 만든 뒤 **Enter** 키를 누릅니다.
5. 취소하려면 **Esc** 키를 누릅니다.

> **마지막 영역 기억**: 직전에 캡처한 영역이 파란 박스로 미리 표시됩니다. 그대로
> **Enter**를 누르면 같은 영역이 즉시 다시 캡처되고, 새로 드래그하면 새 영역으로
> 바뀝니다.

> 아주 작은 드래그(실수로 클릭한 경우)는 취소로 처리되지 않고, 오버레이가 유지되어
> 다시 선택할 수 있습니다.

---

## 4. 전체 화면 캡처 (Capture Full Screen)

- **모니터가 한 대**일 때: 곧바로 해당 화면 전체를 캡처합니다.
- **모니터가 여러 대**일 때: 각 모니터에 번호가 표시된 선택 오버레이가 나타납니다.
  - 캡처할 모니터를 **마우스로 클릭**하거나,
  - 해당 **번호 키(1~9, 또는 숫자 키패드 1~9)** 를 누릅니다.
  - **Esc** 키로 취소합니다.

> **마지막 모니터 기억**: 직전에 캡처한 모니터가 금색 테두리와 `(last)` 표시로
> 강조됩니다. **Enter** 키를 누르면 그 모니터가 즉시 다시 캡처됩니다.

---

## 5. 단축키 (Global Hotkey)

- 기본 단축키는 **Ctrl + Alt + S** 입니다.
- 단축키는 **마지막으로 사용한 캡처 모드**(영역 또는 전체 화면)를 그대로 반복합니다.
  예를 들어 마지막에 영역 캡처를 했다면, 단축키를 누르면 영역 캡처가 시작됩니다.
- 단축키는 어떤 화면에서든(다른 앱을 사용 중이어도) 동작하는 전역 단축키입니다.

> 단축키를 누르면 마지막 캡처 모드가 그대로 실행되며, **직전에 캡처한 영역(또는
> 모니터)이 미리 표시**됩니다. **Enter**를 누르면 기억된 영역/모니터가 즉시 다시
> 캡처되고, 원하면 새로 드래그하거나 다른 모니터를 선택할 수도 있습니다.

## 6. 설정 (Settings)

트레이 메뉴에서 **Settings**를 선택하면 설정 창이 열립니다.

### 저장 폴더 (Save Folder)
- 스크린샷을 저장할 폴더를 지정합니다.
- **Browse** 버튼으로 폴더를 선택할 수 있습니다.
- 기본값은 `내 사진(Pictures)\CaptureIt` 폴더입니다.
- 지정한 폴더를 사용할 수 없게 되면(삭제, 드라이브 분리, 권한 없음 등) 자동으로
  `내 사진(Pictures)\CaptureIt` 폴더로 대체 저장하고 알림을 표시합니다.

### 파일 이름 패턴 (Filename Pattern)
- 확장자 `.png`는 항상 자동으로 붙습니다.
- 기본값은 `Screenshot_{datetime}` 입니다.
- 아래 토큰을 사용할 수 있으며, 설정 창에서 **미리 보기(Preview)** 로 결과를
  확인할 수 있습니다.

| 토큰 | 의미 | 예시 |
|------|------|------|
| `{datetime}` | 날짜_시각 (yyyyMMdd_HHmmss) | `20260702_181604` |
| `{timestamp}` | `{datetime}`과 동일 | `20260702_181604` |
| `{date}` | 날짜 (yyyyMMdd) | `20260702` |
| `{time}` | 시각 (HHmmss) | `181604` |

- 파일 이름에 사용할 수 없는 문자는 자동으로 `_`로 치환됩니다.
- 같은 순간에 여러 번 캡처해서 이름이 겹치면 `_001`, `_002` … 순으로 번호가 붙습니다.

### 단축키 변경 (Hotkey)
- 단축키 입력란을 클릭한 뒤 원하는 키 조합을 누르면 설정됩니다.
- **Ctrl, Alt, Shift, Win 중 하나 이상**을 반드시 포함해야 합니다.
- 이미 Windows나 다른 앱이 사용 중인 조합은 거부되며, 다른 조합을 선택하라는
  안내가 표시됩니다.
- **Save**를 누르면 설정이 저장되고 단축키가 즉시 다시 등록됩니다.
- **Cancel**을 누르면 변경 사항 없이 창을 닫습니다.

### 캡처 지연 (Capture Delay)
- `Off`, `3 seconds`, `5 seconds`, `10 seconds` 중에서 선택할 수 있습니다.
- 지연이 켜져 있으면 **설정한 시간만큼 먼저 기다린 뒤** 영역 선택 오버레이 또는 모니터
  선택 오버레이가 나타납니다.
- 오버레이가 나타나는 순간의 화면이 고정되며, 이후에는 그 고정된 화면 기준으로 영역 또는
  모니터를 선택해 캡처합니다.
- 따라서 지연 시간 동안 메뉴를 열거나, 창 위치를 조정하거나, hover 상태를 만든 다음
  오버레이가 나타났을 때 원하는 부분을 선택하면 됩니다.

설정은 `%AppData%\CaptureIt\settings.json` 에 JSON 형식으로 저장됩니다.

## 7. 문제 해결 (Troubleshooting)

| 증상 | 원인 / 해결 |
|------|-------------|
| 단축키가 동작하지 않음 | 다른 앱이 같은 조합을 사용 중일 수 있습니다. Settings에서 다른 단축키로 변경하세요. |
| 저장 폴더 관련 알림이 뜸 | 지정한 폴더를 사용할 수 없어 `Pictures\CaptureIt`로 대체 저장된 것입니다. Settings에서 유효한 폴더로 변경하세요. |
| 트레이 아이콘이 사라짐 | Windows 탐색기가 재시작되어도 아이콘은 자동으로 복구됩니다. 계속 안 보이면 앱을 다시 실행하세요. |
| 특정 화면이 검게 캡처됨 | UAC 보안 데스크톱이나 DRM 보호 영상은 캡처할 수 없습니다(기술적 한계). |

---

## 8. 알아두면 좋은 제한 사항

- Windows 시작 시 자동 실행 기능은 없습니다(직접 실행).
- 캡처 성공 시 클립보드 복사나 알림은 제공하지 않습니다(의도된 조용한 동작).
- UAC 보안 데스크톱, DRM 보호 콘텐츠는 캡처할 수 없습니다.
- 단축키는 마지막 캡처 모드와 함께 **직전 영역/모니터를 기억**해 미리 표시하며,
  Enter로 즉시 다시 캡처할 수 있습니다.
